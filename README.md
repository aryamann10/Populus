# Populus 🌍

**Populus** is an interactive educational web project designed to explore population dynamics, ecosystem balance, and food web relationships through intuitive visualizations and frontend interactivity.

---

## 🚀 Key Features

* **Population Insights & Data Visualization:** Interactive charts tracking species population changes over time using Chart.js.
* **Ecosystem Balance Simulation:** Dynamic balance impact explorer demonstrating real-time cause-and-effect relationships between species and resources.
* **Interactive Food Web:** Visual trophic structure displaying producers, primary consumers, and top predators with interactive organism cards.
* **Sustainable Solutions:** Educational guides outlining real-world conservation strategies and environmental mitigation efforts.
* **Responsive Layout:** Clean, accessible user interface optimized across desktop and mobile devices via Bootstrap 5.

---

## 🛠️ Built With

* **HTML5:** Semantic page layouts and structural scaffolding.
* **CSS3:** Custom layout styling, responsive utility classes, and transitions.
* **JavaScript (ES6):** Dynamic card generation, DOM filtering, and event handling.
* **Bootstrap 5:** Component framework and responsive grid architecture.
* **Chart.js:** Data visualization and growth trend rendering.

ABOUT THE PROJECT

What is Populus?

Populus is an educational web project that explores how population changes affect species, ecosystems and food webs. The project aims to create awareness about environmental balance and sustainable solutions.

01

Population

Understand how populations grow and the factors that influence their changes over time.

02

Ecosystem

Learn how population changes can affect natural resources, habitats and ecosystem balance.

03

Food Web

Explore relationships between organisms and understand how changes move through a food web.
